### 2. Run it Locally (Requires Installing PHP)
If you want to run it on your own computer:
1. **Install XAMPP**: Download and install **[XAMPP for Windows](https://www.apachefriends.org/index.html)**. This installs PHP, Apache, and MySQL in one package.
2. **Move Project**: Place the project folder inside XAMPP's serving folder (usually `C:\xampp\htdocs\vanixstudio\`).
3. **Start Apache & MySQL**: Open the XAMPP Control Panel and click **Start** next to Apache and MySQL.
4. **Initialize DB**: Go to `http://localhost/phpmyadmin/`, create a database, configure it in `api/.env` (using host `localhost`), and then run the seeder at:
   `http://localhost/vanixstudio/api/seed.php`
5. **Access Site**: Open `http://localhost/vanixstudio/frontend/` in your browser!
